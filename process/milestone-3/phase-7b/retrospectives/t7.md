### 観測された事実（反証可能な signal）

- `dsl_spec.md` §5 AST は `PlacementBind { key, value }` という**実装に
  存在しないヴァリアント**を規範記述していた（`wasamoc/src/ast.rs` の
  `Member` enum に `PlacementBind` は無く `PropertyBind` のみ）。
- `architecture.md` §6.7.9 と `dsl_spec.md` §8 は `Widget { node,
  slot_data }`（構造体ヴァリアント）を示すが、`wasamo-ir/src/lib.rs` の
  landed は `IrMember::Widget(IrChildSlot)`（タプル + named struct）。
- T0 凍結の T7 candidate-ledger bullet は **T6b 挿入（2026-06-24）より前**
  に書かれ、Problem B / Phase-8 demo 除去 / layout findings を含まない。
- marker flip 後、`rg "design draft|not yet implemented" docs/` は
  changelog の歴史行のみにヒット（規範本文に残存ゼロ = flip 完了の反証
  可能 signal）。

### 自己分析（どの層が外れたか）

- 外れていたのは「実行」ではなく **plan.md の前提**（T0 凍結時点の
  divergence 記述が総称的で、かつ T6b 挿入を織り込めていない）。plan を
  「仮説」として扱い、着手時に landed source へ照合したことで D1/D2 と
  T6b carry の欠落を検出・補正できた = **目標（living spec を landed shape
  にピン留め + 候補 ledger 確定）自体は妥当**で、re-cut で達成。
- 「divergence は spec を一読すれば足りる」と即断していたら D1 を見落とす
  ところだった。型定義の実読（grep でなく）が境界事象（設計ドラフトが
  予定した AST ヴァリアントを実装が採らなかった）を露見させた。

### 計画仮説・前提の問い直し（オーナーと）
