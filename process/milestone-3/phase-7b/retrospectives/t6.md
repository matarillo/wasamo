## 目標・前提・計画仮説の再点検

> 後続タスクの retrospective でも流用するダブルループ振り返り欄。
> 実行の巧拙（シングルループ）でなく、**設定した目標・前提・事前計画
> （= 検証すべき仮説）自体が妥当だったか**を、反証可能な signal とともに
> オーナーと問い直す。下の 5 サブセクションがひな型。

### 観測された事実（反証可能な signal）

- plan.md T6 の「same positions as **the old surface**」は live 比較を
  前提するが、bare 構文は T4 で reject されこのブランチでビルド不能 =
  **owner に実行不能な観察を要求していた**。
- same-position 不変条件は T5 が `t5-lightbox-slot-current.png` vs
  T4-pre `3134287` baseline で **pixel 一致**として既に閉じていた(二重
  に owner へ振っていた)。
- preamble は「assistant が host + script を準備」と書くが、plan.md
  checklist に assistant が `[x]` にできる項目が無かった(分離が非監査)。
- owner smoke = **all pass**、fix iteration ゼロ。owner frame
  (`t6-placement-demo.png`)で ZStack 3 位置 + Grid stretch-vs-centered
  対比が確認できた。
- demo Grid は固定トラック(`columns: 220 220 220`)で resize 非追従 —
  star-track / aspect-cell が nested overlay で arrange abort する T5
  finding の帰結(反証 signal にならない仕様内挙動)。

### 自己分析（どの層が外れたか）

- **前提層が外れた(plan.md 仮説)。** T0 凍結時の T6 記述が、後続 T4
  (bare reject)と T5(same-position closure)の結果を反映していな
  かった。plan.md を「仮説」と扱い、着手時に T4/T5 の実績へ照合した
  ことで前提のずれを検出・訂正できた = **目標(owner-visible smoke)
  自体は妥当**で、re-cut で達成。
- **手段の混入は無かった。** owner smoke が assistant 代行不可である
  ことを最初から明確にし、assistant portion(prep)で閉じられる範囲と
  owner-gated 範囲を分離してから着手したため、T5 で起きた「制約を
  環境由来か本質か切り分ける前に手段を諦める」類のシングルループ混入
  は再発しなかった。

### 計画仮説・前提の問い直し（オーナーと）

- owner-smoke task の plan は framing 段階で **(a) assistant が check
  できる prep 項目と (b) owner-gated 項目を分離**し、**(c) 先行 task が
  既に閉じた不変条件(same-position 等)を owner へ二重に振らない**よう
  に書くと、着手時の再考コストが下がる。
- owner に求める観察は **このブランチで物理的に実行可能か**(削除済み
  surface との live 比較を求めていないか)を plan 記述時に点検する。

### 反証可能な是正テスト

- owner-smoke task の **start gate** で「owner に求める各観察は現
  ブランチで実行可能か / 先行 task が既に閉じた証明を再要求していないか」
  を点検する。是正できていれば、owner は実行不能な比較(削除済み
  surface 等)を一度も求められない(反証 signal = owner が「それは
  できない」と返す)。
- owner-smoke task の plan に **assistant が `[x]` にできる prep 項目**が
  少なくとも 1 つあるか点検。無ければ責務分離が非監査(反証 signal =
  reviewer が「assistant は何を準備したのか」を diff から読めない)。
