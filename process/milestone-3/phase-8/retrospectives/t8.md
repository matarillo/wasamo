  line inspection による spec-audit review として実施した。

### 自己分析（どの層が外れたか）

- **計画仮説の修正:** 初期 plan は T8 に public-draft smoke、A11 trace、
  no-silent audit、architecture-family entry を並列に置いていたが、promotion 前の
  readiness audit という親責務で束ねる方が正確だった。
- **前提の修正:** "Gallery final surface に mutation controls が無い" は問題ではないが、
  その理由と coverage evidence を public-facing spec が読者に伝えなければ no-silent
  audit の弱点になる。
- **記録仮説の修正:** `docs/dsl_spec.md` の stale time wording は実装漏れではなく、
  shipped semantics を古い status で読ませる documentary regression だった。

### 計画仮説・前提の問い直し（オーナーと）

- **「T8 で public-draft marker を flip するか」** — しない。
  T8 は promotion 前の gap detection と readiness fixes。Marker flip と promotion
  promotion change-history entry は T11 が実行する。
- **「Final Gallery に mutation controls を戻すべきか」** — 戻さない。
  End-user Gallery surface はそのままにし、Phase 7 verification evidence と §4.15
  authored mutation example への citation で coverage を説明する。
- **「Aspect は T8 で新規 GUI evidence を撮るべきか」** — 撮らない。
  T7 final Gallery visual と Phase 2 tests の citation があり、T8 は public draft
  から reader が再現できるかを smoke する。

### 反証可能な是正テスト

- Future public-draft readiness tasks should include a stale-time-wording scan:
  "not yet shipped", "Phase N only", and old option labels that conflict with
  current implementation status.
- Public spec audits should distinguish revision-history provenance labels from
  spec-body labels; the former may remain, the latter should not drive current
  semantics.
- When final demo UI omits verification controls, the spec audit should require
  an explicit evidence citation to the phase that verified the omitted surface.
- Promotion tasks should require a prior readiness-fix commit before flipping
  public-draft markers, so review can separate content fixes from promotion mechanics.

- **T9 へ:** M3 handoff draft should reuse the T8 no-silent audit and carry-forward
