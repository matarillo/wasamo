## 目標・前提・計画仮説の再点検

### 観測された事実（反証可能な signal）

- The first T2 skeleton exposed real owner-visible issues: clipped-looking
  header Buttons, unreadable tab labels, missing thumbnail padding, and a
  stale lightbox capture coordinate.
- Current `gallery.ui` exercises `column-span`, `row-span`, and direct
  Grid child `slot.*` placement inside the Gallery surface.
- Current `gallery.ui` no longer has a root fill `Box`; header/status rows
  sit on the effective window/backdrop surface, while the thumbnail area is
  still covered by its `#2f343b` content `Box`.
- `gallery-expression-use-cases.md` places the expression support needed
  for real lightbox prev/next navigation outside current M3.
- Saved T2 capture script now reproduces the retained five evidence frames,
  including a scroll-before/after positive control, after the root-fill
  removal.

### 自己分析（どの層が外れたか）

- **良かった点:** Owner comments were treated as intent alignment, not as
  silent pixel tweaking. This led to a more reviewable A1/G(1) table.
- **外れた点:** The first capture script treated coordinates as stable too
  casually. The evidence path only became auditable after re-deriving and
  re-saving the script. This is not only a discipline problem: M3 lacks
  semantic hit-testing/query hooks, so coordinate-based GUI evidence is
  structurally prone to drift after layout changes.
- **計画仮説の外れ:** The initial plan underweighted span/direct-slot
  coverage in the Gallery skeleton. It was feasible to exercise both in T2
  by revising the lightbox layout, so deferring them would have been weaker
  than necessary.

### 方針変更・次回からのルール候補

- For GUI tasks, "accepted screenshot" should imply "saved script can
  reproduce it" unless the log explicitly marks it as manual-only evidence.
- Owner-facing placeholder tables should state both the visual decision and
  the coverage consequence when omitting an old verification control.
- R-2 wording should name the actual acceptance question: `checked` on/off
  must be readable against the final effective background. Mica/backdrop
  should be recorded only as a possible factor that can make that cue
  ambiguous.

### 後続 task への渡し方

- T5 should treat the T2 G(1) / A1 table as the starting contract, not as a
  suggestion.
- T7 must re-capture from the final surface; T2 evidence is a scaffold-level
  smoke, not authoritative phase-end proof.
- T4/T7 own the real R-2 close: once `ToggleButton.checked` exists and T5
  has finalized the tab surface, capture checked/unchecked frames against
  the final effective Gallery background.
- T8 should cite Phase 7 collection/iteration coverage if mutation controls
  stay omitted from the final Gallery UI.
