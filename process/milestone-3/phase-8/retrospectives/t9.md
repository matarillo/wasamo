### 観測された事実（反証可能な signal）

- Claude review found `docs/dsl_spec.md` §4.17 contradicted §4.8 by implying
  bool-driven widget attributes were new in Phase 8, despite `Button.enabled`
  already existing from Phase 1.
- The top status paragraphs in `docs/dsl_spec.md` and `docs/architecture.md`
  still said implementation sync / external-reader smoke were pending, even
  though T8 had already completed that readiness audit.
- The first T9 handoff draft overclaimed "what M3 intentionally did not settle"
  while omitting per-primitive deferrals that properly live in the spec.
- Owner clarification turned phase-vocabulary cleanup from "candidate" into a
  formal pre-1.0 residual, without making it an M3-close blocker.

### 自己分析（どの層が外れたか）

- **責務境界の精度不足:** T9 を "handoff draft" とだけ見ると、spec 本文の stale
  process-state 修正を T11 に送りがちだった。実際には、本文が読者に嘘をつくなら
  T9/G(4) の review packet で直すべきで、T11 は status flip に絞るべきだった。
- **Handoff の粒度仮説の修正:** "M3 residuals" と言うと全 deferral を運びたくなるが、
  parallel spec 化する。Milestone handoff は「roadmap trigger を失うと困るもの」に
  絞る方が正確だった。
- **自分の説明の失敗:** Phase vocabulary cleanup の採録について、作業量を理由に
  迷っているように説明してしまった。正しい論点は M3 実装負荷ではなく、
  public-facing consistency residual として正式に残すかどうかだった。

### 計画仮説・前提の問い直し（オーナーと）

- **「T9 は docs 本文を触るべきか」** — 触る。
  ただし promotion marker / CHANGELOG / public-draft change-history entry は T11。
  T9 は T8 検証済み事実と G(4) review correction を反映する。
- **「M3 handoff は全 deferral を列挙すべきか」** — しない。
  Per-primitive deferral は `docs/dsl_spec.md` が正本。Handoff は roadmap /
  trigger-driven residual と milestone-close ownership に絞る。
- **「Phase vocabulary cleanup は採録するか」** — 採録する。
  M3 では直さないが、pre-1.0 public-facing consistency residual として正式に残す。

### 反証可能な是正テスト

- Promotion 前の review では、"pending", "not yet shipped", "land at close" のような
  process-state wording を、検証状態と公開状態の二軸に分けて scan する。
- Handoff draft には "not a parallel spec" test をかける: その handoff が spec 各節の
  Out of scope / Reserved future surface を再記述し始めたら、scope を戻す。
- Public-facing cleanup residual は、実装負荷ではなく public reader / diagnostics drift
  の観点で採否を判断する。
