## Main Learning

- **R-B が予期した「`build_node` が generic loop を bypass」は的中**。
  ただし placement *vector* は `construct_widget` で構築する方が自然
  (既に `node` を持ち、constructor へ `cell_placements` を渡す必要が
  あるため)。`build_node` から逐次 push するより、両者が同じ
  `node.children` を同順走査する形が並行ベクタ不変を共有 cursor なしで
  保つ。
- **runtime IR と author DSL の文法粒度は別物**。author 側の `1*` vs
  `1 *` adjacency は wasamoc lexer (span 保持) の責務。runtime IR は
  canonical machine format なので span 不要・whitespace 非依存で良く、
  runtime tokenizer に span を足すのは不釣り合い。これは T7 で
  dsl_spec §8 に fold する文法形。
- **多 Cell placement-presence は compile-time-only** (DD-M3-P5-006 が
  runtime 列を `(n/a)` と明記)。runtime validate で row/column 欠落を
  0 default すると、多 Cell 省略は両者 (0,0) 衝突として overlap gate に
  捕まる → defense-in-depth が compile-time-only ルールを再実装せずに
  成立。`grid_multi_cell_omitted_placement_collides_at_origin` で固定。
- **loader を単一の「IR → runtime domain 型」変換点に保つ**と
  `build_layout_tree` が構造的コピーで済み、track 変換と placement 抽出を
  2 層に割らずに済む。R-D の文言から微逸脱したが log.md に根拠を記録。
