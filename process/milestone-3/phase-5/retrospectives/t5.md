## Main Learning

- **DSL に comment 構文がない**。当初 slice 冒頭に `//` 説明コメントを
  置いたところ lexer が `unexpected /` で reject (lexer は `//` /
  `/* */` を skip する経路を持たない)。`.ui` の設計意図 (overflow Cell
  の clip 観測目的、track 構成の根拠) は inline ではなく log.md T5
  entry / plan.md T5 bullet 側に記録する形に倒した。
- **「Grid 外周 clip の visible 観測」は cell 内 overflow ではなく
  Grid 外周 overflow を要する**。per-cell clip は (d) で absence が
  保証されている (`arrange_grid` の非-stretch 軸 natural-extent measure +
  `align_in_cell` の no-clamp) ため、sibling cell へはみ出す content は
  clip されず document-order paint (T6 別観測点) になる。outer-bounds
  clip を観測させるには **Grid の最終行/最終列の cell content を
  Grid 外周の外へ** はみ出させる必要がある。footer (row 2 = 最終行) の
  下方 overflow がこの条件を最小コストで満たす。
- **bounded 軸 stretch + 非-stretch 軸 aspect が決定論的 overflow を作る**。
  footer の h-align は default stretch なので width = span cell 幅 (Grid
  全幅、font-metric 非依存)、v-align: start で height 軸は natural-extent
  probe (INFINITY)。`measure_box` の aspect (w bounded, h unbounded) 分岐
  が height = derive_height(width, 4:1) = width / 4 を返し、これが fixed
  64px footer を確実に超過する。window サイズに依らず overflow が起きる
  ので T6 観測が安定する。
