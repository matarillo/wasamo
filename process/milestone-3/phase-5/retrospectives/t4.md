## Main Learning

- **stretch alignment が Visual-offset assertion を font-metric から
  切り離す**。default (stretch/stretch) cell では `align_in_cell` が
  `(cell_start, cell_extent)` を返し、content の intrinsic size と無関係に
  Box Visual の offset = cell origin・size = cell extent になる。これにより
  Box の中身に依存しない決定論的な geometry assertion が書ける。
- **fixed track は parent allocation が可変でも cell origin を決定論的に
  保つ**。`resolve_axis_tracks` は fixed track を bound と無関係に literal
  値へ解決するので、VStack-rooted fixture で Grid 外周高さが Button の
  font-derived 高さに依存しても、`rows: 50 50` の row boundary は不変。
  → 可変 outer height (regression gate は `> 0` のみ) と決定論的 cell
  geometry (完全 pin) を同一 fixture で両立できる。この性質が
  production-root-shape (item (4) VStack) の (b) assertion を成立させた。
- **Grid child Visual offset は Grid に対して parent-relative**
  (`sync_visuals` の `child_parent_abs = computed.offset`、ScrollView の
  intermediate-Visual 経路と異なり中間 Visual を挟まない)。Cell は
  flatten 済みで `WidgetData::Grid` の children = Cell content child 列
  なので、`grid.children[i].visual` が直接 content child の Visual。
- **unbounded star-axis の到達不能性は ScrollView と同型だが理由が二重**:
  arrange-time は全 catalog parent が finite cell を渡す (ScrollView と
  同じ) ことに加え、Grid は `.ui` で width/height を設定できず常に
  Fill/Fill なので measure-time の Shrink probe 経路も塞がっている。
  両経路を log.md に明記した。
