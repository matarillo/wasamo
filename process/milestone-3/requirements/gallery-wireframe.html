M3 target app — Photo Gallery wireframe

Stable visual reference for the M3 target application (Photo Gallery), as accepted in process/milestone-3/requirements/spec.md. This artifact is the visual input for M3 plan drafting, phase pre-docs, DSL spec drafting, and E2E proof acceptance. Surface decisions (required primitives, grammar surface, out-of-scope items) are normative in the pre-doc, not here.

Source exploratory note: process/milestone-3/requirements/target-app-wireframes.html records the original candidate comparison (cases X / Y / Z / W), weighting analysis, and vocabulary review that led to the Z (Photo Gallery) selection. This extracted reference carries only the visual spec for the accepted Z case.

Main wireframes

Two states of the same window: the default thumbnail grid, and the lightbox state shown when the user activates one thumbnail. Numbered callouts map to the primitives below.

Numbered callouts

  • (1) WrapPanel — top-level container for the thumbnail grid. Children flow along the main axis and wrap to the next row on the cross axis when the viewport main-axis size is exceeded.
  • (2) Box with aspect: 1/1 — square thumbnail cell. Per the accepted pre-doc, AspectRatio is not an independent primitive; the aspect constraint is an attribute on Box. Thumbnail content is a Box + Text placeholder (the Image widget surface is deferred to M4).
  • (3) ZStack overlay — layers the lightbox (scrim + centered photo + caption + nav controls) on top of the dimmed grid. Z order follows document order. The scrim is a Box with fill attribute; opacity styling is out of M3 scope (use an opaque fill if a dim is required).

Supporting layout primitives

  • HStack — the top tab strip (All / Albums / Favorites, with a right-aligned Grid button) is a horizontal linear layout. Linear stacking is the layout primitive set's baseline and is not specific to M3.
  • VStack — the lightbox caption block (title line over metadata line) is a vertical linear layout.

Grammar & binding surfaces visible in these wireframes

  • Conditional rendering — the lightbox subtree is present iff a bool binding (e.g. is_lightbox_open) is true.
  • Repetition — the WrapPanel children are generated by iterating a thumbnail collection binding.
  • Button selected state — the "All / Albums / Favorites" tab strip and the highlighted thumbnail use Button's selected-state surface, driven by a bool binding. Selected-state visual styling beyond the minimal distinction is out of M3 scope.

WrapPanel proof strip

A single static wireframe does not convey viewport-width-dependent re-wrap or vertical overflow. The Photo Gallery's main surface only becomes a proof through the three states shown here: wide (the main wireframe above), narrow re-wrap, and overflow with vertical scroll.

The narrow state exercises WrapPanel's viewport-main-axis-dependent re-wrap; the overflow state exercises ScrollView's minimal surface (clip + content offset binding). Scrollbar widget, wheel handler, and drag are deferred to M4 per the accepted pre-doc.
