## 目標・前提・計画仮説の再点検

T3 では T2 の是正策を、作業開始時と close 時の両方で適用した。
反証可能な signal は **owner-correction count = 0（報告前）** と、
close log に残した `rg` 起点の Implemented-branch test map。単に
`cargo test` が green であることでは close しない、という基準は今回は守れた。

一方で、作業中のダブルループで一つ前提を修正した。最初の実装では
`for` body 内の unknown identifier を広く reject していたが、それは既存の
untyped property value を過剰に縛る。T3 で pin すべき挙動は
「typed binding で未宣言 loop-local 風の読みを落とす」ことであって、
すべての bare identifier を state/binder に限定することではなかった。
この修正を入れてから test map を更新した。
