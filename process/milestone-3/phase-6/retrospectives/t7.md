10. **New cross-task / cross-phase design constraints:** **yes — escalated to
    DD-M3-P6-008 (Proposed), to resolve before Phase 6 closes.**
    - **Root cause (the deeper finding, not just the symptom):** component
      **window** attributes are spliced onto the **root widget's**
      `props` / `bindings` ([`wasamoc/src/lower.rs`](../../../../wasamoc/src/lower.rs#L59)).
      `wasamoc check` sees them as component-level (pre-splice AST) and passes
      *any* name; the runtime loader sees them as widget attributes
      (post-splice IR). Phase 6's ZStack validator is the first widget
      validator to strictly reject unknown props/bindings, so the leaky
      abstraction (window attrs masquerading as widget attrs) surfaced as a
      **dual-gate divergence** the moment the root became a ZStack.
    - **Scope is broader than props.** The same divergence applies to
      **bindings**: a component-level dynamic bind (`bind title = …`, FD-D,
      deferred) is spliced onto `root.bindings` and the ZStack root rejects
      all bindings — latent today, but the reason an allowlist-only patch is
      insufficient. T7's `{title, backdrop, theme}` allowlist is also
      **narrower than the compiler's accept set** (arbitrary component props),
      so a fourth window prop / a typo is accepted by `wasamoc` but rejected
      by a ZStack root.
    - **Interim pinned:** current runtime behavior is reject-outside-allowlist,
      pinned by `nested_zstack_rejects_component_window_prop`,
      `root_zstack_rejects_non_window_component_prop`,
      `root_zstack_rejects_placement_prop`,
      `root_zstack_accepts_component_window_props`,
      `root_zstack_still_rejects_widget_attribute`, and (binding facet)
      `zstack_binding_rejected_at_validate`.
    - **Placement:** not a passive `phase-sync` documentation item — it is a
      runtime-correctness divergence raised as **DD-M3-P6-008** and tracked at
      **plan.md T7b**, time-boxed to land before phase close (the realistic
      home is T7-surfaced / Phase-6-close, not a T6 reopen — T6 had no
      ZStack-root example to exercise it).
11. **Downstream-task revision:** **yes.** Added **T7b** (DD-M3-P6-008
