## Checklist (task-end, items 1-11)

1. **Main learning.** GUI evidence has two separable failure planes:
   runtime visibility and assistant capture. T7 initially looked like a
   rendering failure because `CopyFromScreen` failed and `MainWindowHandle`
   picked a helper HWND, but the owner-visible PID proved the Gallery window
   was actually displayed. The fix was to enumerate the launched process's
   visible top-level windows and match the `"Gallery"` HWND, then run the
   capture with GUI escalation. Separately, the first real launch attempts
   found two validator bugs: component-root window props spliced onto the
   root `IrNode` are not root widget attributes, and ZStack child placement
   props remain valid even when the direct child is another ZStack.
